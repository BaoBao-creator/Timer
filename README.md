# Rubik Timer

Trang web tĩnh tối giản để bấm giờ giải Rubik, dùng HTML, CSS và JavaScript thuần.

## Sử dụng

- **Máy tính:** Giữ `Space` ít nhất 0,5 giây, thả để bắt đầu; nhấn phím bất kỳ để dừng.
- **Điện thoại:** Chạm giữ màn hình ít nhất 0,5 giây, nhấc tay để bắt đầu; chạm lần nữa để dừng.

## Chạy local

Mở trực tiếp `index.html` bằng trình duyệt, hoặc chạy máy chủ tĩnh:

```bash
python -m http.server 8000
```

Rồi truy cập `http://localhost:8000`.

Không cần cài package và không có bước build.
